# Beyond the Heroes — Occurred Entries

This folder contains backstage events the Dungeon Master has established as having **actually occurred** in the Rolling High Club world.

These events are world truth, but they are not automatically player-character knowledge.

They are also reader-visible backstage material, not player-safe by default: in normal player-facing use an occurred/published entry is exposed to player accounts only after an explicit spoiler acknowledgement, and that acknowledgement never creates character knowledge. See `../README.md` and `docs/BTH-01-PLAYER-DM-ACCESS.md`.

Every entry must preserve the knowledge boundary and should link to affected RHC owners instead of becoming a duplicate Hook ledger, NPC state store, location state store or day archive.

Use `../BEYOND_THE_HEROES_TEMPLATE.md` as the starting structure.
