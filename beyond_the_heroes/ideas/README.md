# Beyond the Heroes — Ideas

This folder contains **possible** backstage scenes and developments.

Nothing here has happened in RHC canon merely because it exists here.

Use these files for hook brainstorming, villain/faction possibilities, cinematic cutaway proposals and causal experiments. The Dungeon Master may revise, discard or promote them.

To establish an idea as an event that actually occurred, create/promote an entry under `../entries/` and reconcile any affected RHC domain owners through the normal manual worksystem.
