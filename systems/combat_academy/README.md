# Rolling High Club — Combat Academy

Reusable encounter-design and combat-teaching workspace for RHC.

This directory stores **system/reference templates**, not campaign outcomes. A prepared encounter is not canon merely because it exists.

## Rules

- Use `ENCOUNTER_TEMPLATE.md` when preparing a reusable encounter/scenario.
- A persisted Scenario should identify exactly one Primary Hook in `quests/narrative_hooks.json` when it belongs to campaign continuity.
- A Hook may exist without a Scenario.
- Scenario preparation remains META unless explicitly revealed.
- Encounter mechanics must use the currently approved RHC/D&D rules source and must not silently import Mission 10-specific builds, levels, factions or state.
- Actual results from play are persisted through the normal Quicksave / Final Save workflow.

The existing RHC combat rules/Primer remain authoritative where separately established; this folder does not silently rewrite them.
